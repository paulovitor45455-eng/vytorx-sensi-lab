VYTORX SENSI LAB — PACOTE WEB PARA iPHONE

Este pacote NÃO é um arquivo IPA e não pode ser instalado diretamente como app nativo.
O iPhone precisa acessar o app por uma URL HTTPS para usar “Adicionar à Tela de Início”.

Como testar localmente:
1. Abra index.html em um navegador compatível para testar o protótipo.
2. Para instalar como web app no iPhone, publique os arquivos deste pacote em um serviço HTTPS.
3. Abra a URL no Safari do iPhone.
4. Toque em Compartilhar > Adicionar à Tela de Início.

Para criar um app iOS nativo (IPA), é necessário empacotar o projeto e assinar com as ferramentas e credenciais de desenvolvimento da Apple.
